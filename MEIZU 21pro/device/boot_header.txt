# Measured from the stock image. Offsets are the AOSP boot_img_hdr_v3 layout.

# First 64 bytes of the stock boot.img, decoded as little-endian u32 -- the

#   [ 0] ANDROID!          magic
#   [ 8] 0x02052a00        kernel_size = 33892864
#   [12] 0x00000000        kernel_addr = 0x0
#   [16] 0x1c00017a        os_version   <-- os_version lives at [16], NOT [0] or [24]
#   [20] 0x00000630        header_size = 1584
#   [24] 0x00000000        reserved[0]
#   [40] 0x00000004        header_version = 4
#   [44] ""                cmdline (empty string)
#   [$1580] 0x00000000     signature_size = 0
#
# Format: key=value, one per line, '#' starts a comment. Do NOT quote values.

# NOTE on page_size_field=0
# This is the MEASURED value, not a read error. In boot header v3/v4 the legacy
# v0 "page_size" field is deprecated and written as 0 by mkbootimg. Do not
# "fix" it, and do not use it to compute offsets -- use kernel_offset=4096,
# derived as 2048 + ceil(header_size/2048)*2048 = 2048 + 2048.
